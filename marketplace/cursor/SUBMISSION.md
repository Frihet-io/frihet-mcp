# Cursor marketplace public contract

Frihet ERP provides a local stdio MCP server through `@frihet/mcp-server` and a
remote MCP endpoint at `https://mcp.frihet.io/mcp`.

The canonical catalogue contains 157 operations. The local full profile adds
five fiscal alias names and serves eleven resources and ten prompts. Per-tool
callability and side-effect truth is published in
`_meta["io.frihet/capability"]`; catalogue membership alone is not an
availability guarantee.

Operational submission steps, contacts, approval state, and release sequencing
are intentionally maintained outside this public repository.
