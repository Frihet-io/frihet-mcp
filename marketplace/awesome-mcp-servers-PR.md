# Public directory summary

Frihet ERP is an open-source MCP server for invoicing, expenses, CRM, banking,
POS, HR, and Spanish/EU fiscal workflows.

- repository: `https://github.com/Frihet-io/frihet-mcp`;
- package: `@frihet/mcp-server`;
- MCP identity: `io.frihet/erp`;
- remote endpoint: `https://mcp.frihet.io/mcp`;
- catalogue: 157 canonical operations, with aliases and discovery names counted
  separately by each served profile.

Directory submission ownership and process are intentionally not documented in
this public repository.
